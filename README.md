# Saphira: Bound & Blade

A self-contained, top-down turn-based RPG built with plain HTML, CSS, and canvas. Every map, character, portrait, effect, and sound is generated procedurally in the browser — no external assets, libraries, or build step.

## Play

Serve the folder with any static server, then open `index.html`:

```bash
PORT=3002 ./start.sh
```

## Controls

| Action | Touch | Keyboard |
| --- | --- | --- |
| Move | Left joystick | WASD / arrow keys |
| Sword | Gold **Blade** button | Space / J |
| Interact | Grey **Interact** button | E / F |
| Escape plan | Gold **Plan** button (prison) | P / Escape |
| Battle commands | Battle dock | 1–6 |
| Tilt (optional) | **Tilt** button in the HUD | Ask for motion permission on iOS |

The game prefers landscape on phones and tablets. A portrait prompt offers a **Play anyway** option.

## The Loop

- Explore the Bandit Forest, fight Red Fox minions, and follow the trail to Chief Rusk's camp.
- If Saphira's HP reaches zero she is captured, not killed. She wakes in the Bandit Hideout cell, bound and without her sword.
- Escape by testing the ropes (exactly 50% luck), stealing the guard's knife and cutting free, then sneaking past patrol vision cones to the stairs. Getting spotted ties her up again — but she keeps the knife.
- Escape returns her to the forest for revenge and the final duel with Chief Rusk.

No game over, no external dependencies.
